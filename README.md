# TrueFace Web Liveness SDK (Public Distribution)

This repository distributes the public binaries and release assets for the TrueFace Web Liveness SDK via the jsDelivr CDN.

## CDN Links

### CSS
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/trueface-dev/web-artifact@latest/trueface-web-sdk.css">
```

### JavaScript
```html
<script src="https://cdn.jsdelivr.net/gh/trueface-dev/web-artifact@latest/trueface-web-sdk.js"></script>
```
